XIVTarget's default font is Expressway from EllesmereUI. XIV.ttf (M PLUS 1p Medium by The M+
Project Authors) is the fallback when EllesmereUI isn't installed, and is also in the Font
dropdown. It's licensed under the SIL Open Font License; see OFL.txt.

To use a different font, replace XIV.ttf with your own file under the same name, then restart
the game (a /reload won't pick up a changed font file).
